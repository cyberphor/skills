# `skills`
Agent skills for approaching software-related problems like how [Victor Fernandez III](https://github.com/cyberphor) would.

## Contributing

* Update `CHANGELOG.md` when making changes to any of the skills in this repository.
* Add changes to an explicit current or next planned release section in `CHANGELOG.md`.
* Never modify a published or tagged release section.
* If the planned version is unknown or no next-release section exists, ask the user instead of selecting a version or editing the latest released section.
* Do not add read-only activity or changes made outside this repository to `CHANGELOG.md`.
