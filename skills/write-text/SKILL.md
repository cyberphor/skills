# How to Write Text

## Language

* Follow ASD-STE100 Simplified Technical English, Issue 9.
* Preserve the intended meaning and technical accuracy.
* Use the same term for the same item throughout the text.
* Use approved vocabulary where possible.
* Keep necessary technical names and terms.

## Sentences

* Use active voice.
* Use direct commands for instructions.
* Give one instruction per sentence.
* Limit procedural sentences to 20 words.
* Limit descriptive sentences to 25 words.
* Put conditions before instructions.
* Start instructions with a specific verb and its object.

## Lists

* Use flat bullet lists unless the user requests another format.
* Put procedural steps in execution order.
* Put other lists in alphabetical order unless meaning requires a different order.
* Follow the user's requested order.

## Punctuation

* Do not use semicolons.
